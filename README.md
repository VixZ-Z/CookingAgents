# Human-Robot Collaboration in a Home-Care Kitchen

The current CookingAgents experiment uses the same divided kitchen for reactive
and anticipatory robots, six recipes and three seeded 60-second meal periods.
See [the experiment guide](overcookedAI/EXPERIMENT.md) for launch commands,
preparation steps, logging, reproducibility and limitations.

This repository contains two projects . Both use a cooking scenario in which a
robot collaborates with a human, motivated by healthcare and home-care settings 
(e.g., assisting an elderly person with limited mobility).

| Project | Folder | Focus |
|---|---|---|
| 1. Research project | `overcookedAI/` | Anticipatory robot behaviour in an Overcooked-style game |
| 2. Sense-Think-Act | `sense-think-act/` | Intent recognition under noise and decision-making |
