# Human-Robot Collaboration in a Home-Care Kitchen

This repository contains two projects . Both use a cooking scenario in which a
robot collaborates with a human, motivated by healthcare and home-care settings 
(e.g., assisting an elderly person with limited mobility).

| Project | Folder | Focus |
|---|---|---|
| 1. Research project | `project1_overcooked/` | Adaptive robot behaviour in an Overcooked-style game |
| 2. Sense-Think-Act | `project2_sense_think_act/` | Intent recognition under noise and decision-making |
